MIND GARDEN 3.8.4 — AFFECTED FILES ONLY

This is an update for your existing Mind Garden v3.8 / v3.8.3 project.
It is not a complete standalone Cloudflare upload.

1. Keep a backup of your existing project.
2. Copy this patch's public folder INTO your existing project's public folder.
   Replace index.html and sw.js, and add the two garden-ui-384 bundle files.
   Keep all existing images, sounds, animal models, functions and database files.
3. Deploy the complete updated existing project using your usual Cloudflare method.
   For a static-assets directory, use the contents of the merged public folder.
   Online multiplayer still requires the existing Cloudflare Functions/D1 backend.
4. Reload the app. Settings should show Mind Garden 3.8.4.
   If necessary close other app tabs, reopen, and use Ctrl+Shift+R once.
   Do not clear site data: history and personal media live in this browser.

All four deployment files must be applied together. Replacing only the CSS
cannot add the JavaScript features or update the release/cache references.
No SQL migration or backend change is required.

NEW FEATURES AND FIXES
- Nature sounds button shows only On / Off; no 'tap to begin'.
- Larger guided-activity caption, with responsive wrapping.
- Original inspirational thought changes each local calendar day (English/Chinese).
- Animal, bird and insect movement uses shared collision safety bounds.
- Settings > Export my data: JSON profile/preferences backup and activity CSV.
- Saving a name in Play Together collapses the inline editor on success.
  It remains open if saving fails. The separate rename dialog also closes on success.
- Scene label/video controls have reserved space below the new quote.

EXPORT SCOPE
Exports contain only the selected player's retained data on this device.
JSON includes preferences. CSV includes retained activity, stars/levels,
garden growth and received online round scores. Historical records which were
never stored cannot be reconstructed. Online result recording starts in 3.8.4.
Photos, videos, music files, authentication tokens and other players are excluded.
Automatic import/restore is not included in this release.

WILDLIFE
The existing stylized 3D animals are retained, with GIF fallback when WebGL is
unavailable. Safety bounds cover creatures together; paths yield or bend around
one another. On a very crowded viewport, a creature can temporarily be hidden.
Background trees/benches are painted scenery, not physical collision objects.

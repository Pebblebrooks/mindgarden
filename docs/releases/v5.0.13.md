# Mind Garden v5.0.13

Add games now opens a dedicated selection dialog. Already selected games are omitted; search and category filters preserve pending choices. Add selected games saves them and returns to My Games; Cancel and the header Back button leave the selection unchanged. The collection footer has a full spacing row before its action buttons and centered status/Undo feedback.

Joined rooms use **Return to room**. This path restores the selected room and requests its status without calling create or join. **New room** opens the separate creation form. Back sits in the shared top-left header; room closure explanations appear on the information control beside New room. Closed/left memberships are removed immediately from cached My rooms cards. Rooms, Lobby and My rooms retain their fixed shell.

My Progress has its information control immediately beside the title and a centered Done action. Garden Pets uses the width of the game surface (up to 1080px outer width on desktop), places the pet beside its controls on larger screens, and opens expanded without changing home-pet visibility. The compact duplicate show/hide controls are omitted within the game. Smaller screens use one scrolling play area.

Returning kept the exact room code and database room count and sent no create/join request.
- Eight independent UI clients completed the multiplayer lifecycle; multiroom occupancy, idempotent creation and scoped closure passed.
- 126 bilingual game setups/launches and 324 next/replay/easier transitions passed. Pet gestures, pause, visibility isolation and audio checks passed.
- Browser audit inspected all 56 catalogue cards at 1024, 768, 390 and 667px viewport widths. English normal and 200% text and Chinese 200% text had centered labels/icons and no card content overflow. Light and dark selection contrast checked; duplicate selected-card tick corrected.
- Browser checks confirmed identical room-directory dimensions across all three tabs; top-left Back; title-adjacent progress info; centered Done; centered add/remove messages; a 28px instruction-to-action gap; phone picker actions; and fully visible desktop pet/controls without inner scrolling at normal text size. Local room fixtures are never deployed.
- No database migration or backend changes. Existing scenery corrections from v5.0.12 are retained.

Limits: browser viewport tests do not certify physical devices or screen readers. The old standalone garden-activities test targets retired dot-game controls and fails before its pet section; the current pet regression and maintained game setup/transition suites cover this release's changes. No claim is made that every possible gameplay defect has been eliminated.

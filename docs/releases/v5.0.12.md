# Mind Garden v5.0.12

My Games now shares the All Games page, adaptive cards, search and category filter. The grid grows with the selected games, without three-item pagination. Add, remove and undo preserve player scores and per-collection game settings. Play my selection follows the complete saved order, including games hidden by the current search.

Play Together uses a 920 × 640 CSS-pixel shell on desktop, capped to the viewport on smaller screens. Rooms, Lobby, My rooms, join/create forms and the waiting room use the same shell. Tabs and footer remain visible while the body scrolls. Player lists use native dropdowns and retain selection during polling. Existing room protocol, eight-player capacity, multiroom membership and Begin fairness remain unchanged.

Built-in scenery and thumbnails retain source colours and contrast. The blanket sepia/desaturation/contrast reduction is removed. Static low-opacity sky texture reduces the appearance of gradient steps without blurring image edges. All 22 paired sceneries remain; personal media is excluded. This does not reconstruct detail absent from source artwork.

Audit corrections include: unrelated popup decoration no longer reparents the My Games page footer; saved rankings retain their own responsive pagination helper; invitation banners do not cover the room-directory footer; active tabs stay visibly selected in light and dark themes; large-text room cards stack; user names are protected from translation in player dropdowns; singular session counts and bilingual About/Quick Guide paths are current.

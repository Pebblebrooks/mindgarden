# Mind Garden v5.0.14

Matching Pairs now calculates explicit square grid tracks from the actual allocated play area, including gaps and footer space. Two obsolete viewport-based fitters were removed. Cards preserve a 48px minimum target and use scrolling only when the complete deck cannot fit safely.

Mental Sums, Number Patterns, Times Tables, Word Builder, Count Down and other direct answer grids retain the full available width inside centered layouts. Picture-choice fitting accounts for sibling prompts and answer rows, fixing Count It. On desktop, dot routes, colour links, jigsaw, path and bingo boards sit beside their instructions and actions. Small screens retain a stacked layout. Invitation banners cannot cover an open popup or active game.

Leaderboard uses ten rows per page and a taller bounded panel, with a centered Done button. Ten rows were simultaneously visible at 768 x 900 in browser QA. Smaller screens scroll the table. Saved rankings uses a taller panel, distinct row gaps and right-side help beside Room; empty results retain accessible help.

## Validation

- Build, syntax checks, the full test:v502 release suite, board geometry and analytics pagination regressions passed.
- 42 board geometries cover 6–24 cards, both axes, minimum touch size, the level-8 overlap regression and constrained scrolling.
- Browser audit covered initial play surfaces for 55 games and the embedded Move & Remember setup. No horizontal overflow or overlapping grid cells was found in the inspected states. The initial audit found and corrected narrow numeric/word choices and hidden Count It answers.
- Direct desktop checks of Mental Sums, Number Patterns, Times Tables, Word Builder, Count Down and Count It confirmed answers visible without inner scrolling.
- Matching Pairs level 8 fit fully at desktop, phone portrait, phone landscape and phone 200% text. Representative number, counting, link and rankings screens had no horizontal overflow at phone 200%; long content retained vertical scrolling.
- Personal progression: 126 bilingual setups/launches and 324 result transitions. Current route UI, expansion games, movement integration and 48 bilingual movement flows passed. Retired dot and catalogue selectors in older tests were updated to current controls.
- English and Chinese About latest improvements updated for board fit, ten-player rankings, selection picker and non-obstructing invitations. Existing setup/privacy paths retained.

Limits: these checks cover the specified browser states, not every possible game state, physical device or assistive technology. Dense Sudoku, long instructions, large text and short landscape viewports may still require scrolling to preserve readable text and usable controls. No database migration or backend change is included. Local QA fixtures are excluded from the release.

# Game expansion roadmap

Use original Mind Garden code, artwork and curated question banks. Games for the Brain is inspiration for mechanics, not a source to copy assets or infer clinical benefit.

## First release — implemented in v4.0.55

- Sudoku: 4×4, then 6×6 and optional 9×9; uniquely solvable boards, notes and explanations for hints. Board size and clue density grow by rank; every generated puzzle is checked for a unique solution.
- Stroop Colour Match: select ink colour rather than read the word; begin with matching word/colour, introduce conflicts, then optional rule switching. Untimed first; show accuracy and optional response times, never an IQ or dementia score. Separate non-colour interference activity for players who cannot reliably distinguish the colours.
- Flag Match: Southeast Asia pack first, then wider regions and similar-flag comparisons. Use verified flag artwork, country names and typed recall; grow distractor similarity and recall demands.
- Scene Recall: extend the existing memory collection with original garden/home scenes. Ask about objects, locations and counts after a user-controlled viewing period.

## Following group

- Word Rescue: Hangman-style hidden-word guessing with a garden illustration instead of hanging imagery. Familiar categories, then fewer clues and longer words. Chinese requires a separately designed character/phrase activity, not a literal letter translation.
- Mini Crosswords: curated small English grids, clue-first mobile input, optional word bank. Create independent Chinese word/character puzzles rather than automatic translations.
- Checkers: tutorials and capture puzzles, then a complete board against a local opponent; later online play if requested. Make the chosen rule set and mandatory captures explicit, highlight legal moves and explain hints.
- Garden Code: infer a hidden sequence from right-symbol/right-position feedback. Use colours plus shapes or numbers so colour is not the only signal.
- Word Trails: remember a word, then tap adjacent letters in a small grid; offer drag as an alternative rather than mouse-only interaction.
- Shuffled Picture Recall: extend What's Missing with a replacement image and shuffled positions, avoiding a duplicate game card.

## Specialist content

- Sign-language learning: propose Singapore Sign Language (SgSL), using licensed video reviewed by fluent Deaf signers. Begin with recognising everyday signs, then short sequences. Do not present AI-generated gestures as verified signs or claim camera-based signing assessment.
- Colour activities: recreational shade matching and ordering can be included. Any colour-vision screening needs a separate clinically reviewed scope and appropriate validated material; ordinary game results must not diagnose colour blindness.

## Shared requirements

All new games inherit the approved icon/tooltip layout, plain background, pause and exit confirmation, yellow hints, clear round progress, accessible touch/keyboard alternatives, bilingual instructions, assisted-answer records and 15 meaningful levels within the selected mode. Long board games can save a local unfinished session only when that behaviour has been implemented and tested. Prefer solo-first delivery; multiplayer needs explicit synchronisation and fair hint rules.

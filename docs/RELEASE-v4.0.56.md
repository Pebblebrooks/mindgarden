# v4.0.56 — Sage & Teal light mode

Applies the approved palette across light-mode menus, popups, navigation, game cards, tabs, form fields and movement menus. Deep teal primary actions use white text; selected tabs use pale teal; cards use sage on ivory surfaces. Dark mode and high-contrast overrides remain separate.

Information controls retain 44px touch targets, keyboard focus and existing help behaviour. Their decorative outer border/shadow is removed. My Games card help is centred above the name; setup help is centred below the explanation.

Bilingual About describes the new palette and placement. No data migration or gameplay-rule change.

MIND GARDEN v3.8.7

APPROVED CHANGES
- Keep the navbar on one row and measure available space before showing optional
  controls. Overflow controls remain accessible in the hamburger menu.
- Recalculate the navbar as viewport size, text size, language or font metrics
  change. Keep visible main links centered and utility controls right aligned.
- Show the hamburger symbol without "More"; retain accessible menu labels.
- Include About, Contact and synchronized text-size controls in the menu.
- Keep menu controls usable in narrow and short viewports; support keyboard
  dismissal and return focus appropriately.
- Fix the bouquet SVG's conflicting width rule. Artwork now fits within
  340 x 289 pixels, scales down on narrow screens and preserves its aspect ratio.
  Large-text stacked cards no longer stretch the artwork to full page width.
- Remove the leftover side padding from the stacked large-text bouquet card.
- Update the app version and coherent offline assets to v3.8.7.

VALIDATION
- Browser viewport checks from 320 to 1920 pixels, including 100%, 140% and
  200% text. Navbar stayed on one row without overlapping controls in the tested
  combinations; English and Chinese controls were checked.
- Bouquet layout checked at 390, 768 and 1920 pixel iframe widths, each with
  100%, 140% and 200% text. Artwork remained within its size limits and aspect
  ratio, rotation controls stayed inside the card, and there was no horizontal
  page overflow in these checks.
- Navigation, accessibility restoration, shipped UI and offline-cache checks
  passed during preparation. These are viewport simulations, not physical
  iPhone, iPad or Android device certification.
- No new database migration or server changes. Live multiplayer/database state
  was not modified or revalidated as part of this UI-only update.

PACKAGE CONTENTS
Four prebuilt application files plus installation instructions, this changelog
and checksums. Unchanged images, sounds, backend files and earlier SQL are not
duplicated. Requires the existing complete v3.8.6 project.
